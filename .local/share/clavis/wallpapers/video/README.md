# Video wallpapers (mpvpaper)

Place `.mp4`, `.webm`, `.mkv` or `.mov` files here. They appear in Clavis wallpaper picker after a rescan.

Large binaries are not committed; copy from another machine (for example `nyxniri:~/Pictures/Wallpapers/video/`).

Requires `mpvpaper` (prefer `mpvpaper-git` >= 1.9) and `ffmpeg`.
